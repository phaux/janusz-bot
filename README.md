## Wymagania

- [Deno 2](https://deno.com/)
- [Ollama](https://ollama.com/)

## Uruchamianie

1. Stwórz własnego bota na telegramie. Napisz do [Ojca Botowego](https://t.me/BotFather).
2. Stwórz plik `.env`, a w nim: `TG_BOT_TOKEN=twój_token`.
3. Upewnij się że demon olamy działa.
4. Uruchom za pomocą `deno run --env-file --allow-env --allow-net main.ts`.
